# Crear bases de datos
Para crear una base de datos vamos a 
utilizar el comando **CREATE DATABASE**

En el panel de código escribimos:

```sql
    CREATE DATABASE nombreBasae;
```

> Para este curso nos vamos a referir a una base de datos llamada "introdb"  
 Para crearla escribimos:

```sql
     CREATE DATABASE introdb;
```


> Ejemplo avanzado
```sql
    CREATE DATABASE nombre   
      CHARACTER SET utf8mb4  
      COLLATE utf8mb4_0900_ci;  
```


## Eliminar una base de datos
Para eliminar una base de datos 
utilizamos el comando **DROP DATABASE**

En el panel de código escribimos:

```sql
    DROP DATABASE nombreBasae;
```
